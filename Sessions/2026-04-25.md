# Session — 2026-04-25

## Decisions

- **Shader Pattern Aspect Ratio Fix**: `scaleY = scale / uAspect` statt symmetrischem Scale. `scale` = Spaltenanzahl, Reihen passen sich automatisch an. Vorher: `* vec2(uAspect, 1.0)` fixte nur Dot-Form, nicht Grid-Abstände.
- **Layout Select (Dots mode)**: Grid / Hex / Diagonal als compile-time branching Property. Hex: jede 2. Reihe +0.5 Versatz. Diagonal: 45° Rotation im pixel-square UV-Raum.
- **Time Animation**: `time`-Port + `timeSpeed`-Property (default 0, keine ungewollte Animation). Dots: horizontaler UV-Scroll (`coord2D + vec2(time, 0)`). Lines: Phase-Offset (`dot(coord, dir) * scale + time`). Pattern: `uTime * timeSpeed` als Auto-Animation-Fallback.
- **Triplanar Projection**: Geplant aber NOCH NICHT implementiert. User hat "Ja bitte" bestätigt — nächste Session starten. Grund: atan-basierte UV hat harte Diskontinuität am Kugel-Rücken, besonders sichtbar bei Hex und Diagonal.
