## Key Decisions

**Port name collision:** ReactFlow uses port `name` as the handle DOM ID. Input and output ports with the same `name` on one node cause the edge to connect to the wrong handle. Solution: input port uses `name: 'source'`, user-visible label `→ Texture`.

**Ghost handle (tried and reverted):** Added 0x0 invisible `alwaysHandle` port to keep `source` handle always in DOM. Caused edge misalignment because ReactFlow attaches the edge to the ghost handle's Y position. Removed entirely — `visibleWhen` is the correct approach; user sets mode first, then connects.

**Tileable noise:** Standard fBm has discontinuities at u=0/u=1. Fix: `tileX = round(scale)`, each octave's lattice wraps at `tileX * freq`. Canvas samples at `(i/resolution) * tileX`. Combined with `RepeatWrapping`, the texture tiles seamlessly.

**Cap-rim seam (Cylinder/Capsule):** Three.js procedural geometry has independent UV islands for cap (radial) and side (rectangular) at the same 3D vertex. Displacement gap is not fixable with tiling. Deferred to Quad-Mesh Primitives (Phase 6).
